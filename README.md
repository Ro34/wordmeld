# 词不一样就跑步 · 本地版 🐤

「词不一样就跑步」挑战的**局域网本地版**：两个人各想一个词同时揭晓，没撞上就从这两个词继续联想，看第几轮能想到同一个词。词不一样但说的是同一个东西（番茄/西红柿）？双方都点头也算成功。

与原版在线版的区别：**服务器跑在你自己的电脑上，两台手机连同一 WiFi 即可**，延迟在几毫秒级，不需要外网，也不需要安装任何 App。

## 快速开始

```bash
npm install
npm start
```

启动后终端会打印局域网地址和一个**可直接扫描的二维码**。

1. 电脑浏览器打开 `http://localhost:3000`（也可以不打开）
2. 两台手机连上**同一个 WiFi**，扫终端里（或页面上）的二维码
3. 一人点「创建房间」，另一人扫码/输房间码加入，人齐自动开局

> 如果扫码后打不开：确认手机和电脑连的是同一个路由器；个别路由器开启了「AP 隔离 / 访客网络隔离」，关掉即可。

## 玩法规则

- 每轮限时（30/60 秒或自定义 10~300 秒），两人各写一个词，**都提交或时间到一起揭晓**
- 词一样 → 🎉 通关，可生成**记录照片**保存/分享
- 词不一样 → 从这两个词继续联想，进入下一轮；觉得说的是**同一个东西**时，双方都点「我们说的是同一个东西」也算成功
- 随时可以退出；中途刷新页面/断网会自动回到原座位

## 技术实现

| | |
|---|---|
| 服务器 | Node.js 原生 `http` + `ws`（WebSocket），无框架 |
| 实时同步 | 服务器权威状态机，每条消息带 `serverNow` 校准时钟，倒计时以服务器为准 |
| 二维码 | `qrcode` 同时输出终端版（启动时）和 SVG 端点 `/qr?d=`（页面内） |
| 前端 | 零构建原生 ES Module，单页渲染，`sessionStorage` 保存玩家身份支持断线重连 |
| 设计 | claymorphism 软糯质感 × friendly 粉彩 × bento 卡片（参考 [awesome-design-skills](https://github.com/bergside/awesome-design-skills)，已收录在 `design-skills/`） |
| 吉祥物 | 原创小黄鸡 × 小白鸭 SVG（致敬莎莉鸡的精神，但不侵犯 LINE Friends 造型） |

## 已知边界

- v1 仅支持 2 人房间（服务端座位数组留了扩展位）
- 「同一个东西」判定靠双方手动确认（AI 判词预留为后续增强）
- 空词（没想出来）会以「——」参与揭晓，双方都空则该轮作废可继续

## 环境变量

- `PORT`：服务端口，默认 `3000`
