怎么玩

四步，跑到同一个词上

从创建房间到脑回路相遇，最快 30 秒

  1. 1

    🖥️ 创建房间

    一台电脑跑 npm start 当主机，自动生成 4 位房间码——I L O 0 1 这些容易看错的字母都剔掉了。

  2. 2

    📱 扫码加入

    对方连同一 WiFi，扫码、点邀请链接或手动输码都行。座位亮起来，人齐自动开局。

  3. 3

    ✍️ 同时写词

    30 / 60 / 自定义秒，倒计时以服务器为准。写好就锁定，揭晓前谁也看不到谁的。

  4. 4

    🔀 同时揭晓

    词一样，直接通关！不一样，就从这两个词之间继续联想，直到你们的脑回路相遇。
